# 01 · 从零跑起来

> **这篇给完全没写过安卓 App 的人。**
> 目标：从「电脑上什么都没有」到「手机上能看到这个 App 跑起来」，全程只复制命令。

---

## 30 秒版

1. 装 **Android Studio**（一个软件，装了它 JDK、SDK、模拟器全都有了）
2. 用 Android Studio 打开工程根目录，等右下角进度条走完
3. 手机插数据线，开「开发者选项 → USB 调试」，点绿色的 ▶

就这三步。下面每一步的细节和踩坑。

---

## 上手版

### 第 1 步：装 Android Studio

去 <https://developer.android.com/studio> 下载安装。

⚠️ **不要自己去装 JDK、不要自己配 SDK**。Android Studio 自带一套匹配好的，你手动装很容易版本对不上，
然后卡在一个看不懂的报错上。装完打开一次，让它把 SDK 组件下完（首次会下几个 G，挂着就行）。

装好后确认一件事：**Settings → Languages & Frameworks → Android SDK → SDK Platforms**
里至少要勾一个 Android 15 (API 35) —— 这个工程的 `compileSdk` 是 35。

### 第 2 步：拿到代码

```bash
git clone <本仓库地址> DayLedger
cd DayLedger
```

没有 git 的话，在 GitHub 页面点 `Code → Download ZIP`，解压也一样。

### 第 3 步：让手机能被电脑认出来

1. 手机上「设置 → 关于手机 → 版本号」**连点 7 次**，会开出「开发者选项」
2. 回到设置 → 系统 → 开发者选项 → 打开 **USB 调试**
3. 数据线连电脑，手机会弹「允许 USB 调试吗」，勾上「一律允许」再确定

验证：在工程根目录执行

```bash
adb devices
```

看到一行 `xxxxxx  device` 就对了。如果显示 `unauthorized`，是手机上没点「允许」；
如果显示 `no permissions` 或者什么都没有，换一根**能传数据**的线（很多充电线只有电没有数据）。

### 第 4 步：跑起来

**方法 A（图形界面，推荐新手）**
Android Studio → `File → Open` 选工程根目录（就是有 `settings.gradle.kts` 的那一层）→
等右下角「Gradle Sync」走完 → 顶部设备下拉框里选中你的手机 → 点绿色 ▶。

**方法 B（命令行，适合反复改的人）**

```bash
# Windows 用 gradlew.bat 代替 ./gradlew
./gradlew :app:installDebug
```

第一次会下载依赖，**可能要十几分钟**（网络慢的话更久），这是正常的。

### 第 5 步：你看到了什么

App 一启动会自动导入 `app/src/main/assets/legacy_timelog.json` ——
**这是一份 60 天的合成演示数据**（不是任何人的真实记录），所以你一进去就有内容看：

- 时间线上一整天的彩色段
- 统计页有周/月/年的柱子和曲线
- 事项、分类、标签都是配好的

想回到空库：**设置 → 导入旧数据 → 撤销导入**。

## 深挖版：常见报错逐个解

按「你看到的报错原文」查。

### `SDK location not found` / `local.properties` 相关

Android Studio 打开工程时会自动生成 `local.properties`（里面写着你的 SDK 路径）。
如果你是用命令行跑的、或者从别处拷来的工程，这个文件可能不存在：

```properties
# local.properties —— 这个文件不进版本库，每台机器自己生成
sdk.dir=C\:\\Users\\你的用户名\\AppData\\Local\\Android\\Sdk
```

把路径换成你自己的（Android Studio 里 `Settings → Android SDK` 页面上能看到 SDK 位置）。
文件路径里的反斜杠要写成双斜杠，冒号要转义。

### `Could not find cmdline-tools` / `Unsupported class file major version`

两个不同的原因，别混：

- **cmdline-tools**：Android Studio 的 SDK Manager → `SDK Tools` 标签页 → 勾上
  `Android SDK Command-line Tools (latest)` → Apply。
- **class file major version 6x**：JDK 版本不对。这个工程要求 **JDK 17**。
  `File → Project Structure → SDK Location → Gradle JDK` 选 17 或 21（不要用 JDK 8 / 11）。

### Gradle 下载卡住 / `Connection timed out`

首次构建要从 `services.gradle.org` 和 Maven Central 下东西，国内经常慢。两个办法：

1. **在 Android Studio 里等**（它有断点续传，比命令行友好）
2. 让 Gradle 走代理：在工程根目录的 `gradle.properties` 里加
   ```properties
   systemProp.https.proxyHost=127.0.0.1
   systemProp.https.proxyPort=你的代理端口
   ```
   ⚠️ 前提是你**真的**开着代理。代理没开却配了这一行，症状是「所有依赖都下不下来」，
   而报错只说超时，完全看不出是代理的锅 —— 这个坑本项目的作者亲自踩过。

### `INSTALL_FAILED_UPDATE_INCOMPATIBLE`

手机上装着一个**签名不一样**的同名 App。先卸掉旧的：

```bash
adb uninstall com.misaka.timelog
```

再装。注意这会**清掉手机上那个 App 的所有数据**，如果你已经有真实记录，先想清楚。

### `KSP version mismatch` / `ksp-2.0.21-xxx not found`

KSP 的版本必须和 Kotlin 版本**严格对应**。这个工程的配置是：

```toml
kotlin = "2.0.21"
ksp = "2.0.21-1.0.28"     # 前缀必须与 kotlin 完全一致
```

改 Kotlin 版本时，KSP 版本必须跟着换（去 <https://github.com/google/ksp/releases> 找对应版本）。
改错的表现是「Room 生成的代码找不到」。

### 编译过了但装不上：`minSdk 26`

这个工程最低支持 **Android 8.0**。更老的手机装不上，这是刻意的（通知渠道、前台服务这些现代 API 从 26 才开始规范）。

### 跑测试：`./gradlew :app:testDebugUnitTest`

525 条断言，全部跑在电脑上（用 Robolectric 模拟 Android 环境），**不需要手机也不需要模拟器**。
大约 1 分钟。

首次跑会多花几分钟编译测试代码，之后改一处源码再跑通常 30 秒内。

## 想改第一个功能？试试这个

最安全的第一刀：**改一个事项的名字或颜色**。

1. 打开 `app/src/main/java/com/misaka/timelog/data/SeedData.kt`
2. 找到 `private val CATS = listOf(...)`，里面是 10 个一级分类，每行形如
   `SeedCat("work", "赚钱营生", "#8A9A3C")`
3. 把 `"赚钱营生"` 改成你想要的字，或者改那个颜色值
4. 重新跑，卸载重装（种子只在建库时写入一次，改完要清数据才看得到）

⚠️ 为什么必须卸载重装：种子数据是**建库那一刻**写进去的。已经建好的库不会因为改了代码而变。
这也意味着真实用户的分类不会因为升级而丢 —— 详见 [06 数据怎么存的](06-数据怎么存的.md)。

想看更实用的修改（加分类、换配色、加图表、改模板逻辑），去
[07 改它：常见修改](07-改它-常见修改.md)。
